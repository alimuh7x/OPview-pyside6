# OPView v2.0.0

OPView 2.0 adds Multi Property analysis and expands the visualization and comparison workflows introduced in v1.0.0.

## Highlights

- **Multi Property:** compare several properties of one VTK file with independent ranges, palettes, and PNG export.
- **Single View:** rectangle-based range selection, automatic colors based on the visible region, vector and phase overlays, rotation, line scans, and point or whole-field history plots.
- **Linked dataset tabs:** share numeric timesteps and rotation; panels without the selected timestep keep their current file.
- **Multi View:** compare timesteps with shared color controls, editable legends, line scans, and frequency histograms.
- **Custom Graph:** plot text-data columns on two Y axes, convert units, apply formulas using other columns, and preview or export reveal animations.
- **Scientific labels:** shared symbol pickers offer Greek letters, units, powers, and ion charges ¹⁺, ²⁺, ³⁺, ⁴⁺. On-screen colorbars and analysis axes/legends use bundled STIX italic Greek glyphs.
- **Software rendering:** use `OPVIEW_NO_GPU=1` on Linux or the no-GPU source launcher on Windows when graphics acceleration is unavailable.

## Downloads

- **Windows x64:** install `OPView-2.0.0-win64.exe`.
- **Ubuntu 22.04+ x64:** run `sudo apt install ./opview_2.0.0_amd64.deb`.
- **Linux x64 AppImage:** make `OPView-2.0.0-x86_64.AppImage` executable, then run it on a compatible glibc-based distribution.
- **SHA256SUMS.txt:** checksums for all three packages.

The packages include Python and application dependencies. MP4 export additionally requires `ffmpeg` on your PATH.

## Documentation and limitations

The updated [user guide](https://github.com/alimuh7x/OPview-pyside6/blob/v2.0.0/doc/Documentation.md) covers all four views, installation from source, controls, exports, troubleshooting, and debug mode. See the [changelog](https://github.com/alimuh7x/OPview-pyside6/blob/v2.0.0/CHANGELOG.md) for the full changes since v1.0.0.

- Heatmap PNG exports use a separate rendering path; Greek typography can differ from on-screen labels.
- The bundled Roboto Condensed asset is invalid; the application safely uses a system font for its interface. The bundled STIX Greek font is valid.
- Some legacy source tests still expect older layouts or removed helpers. They are tracked separately from the frozen-package startup and dependency smoke tests used by the release workflow.
